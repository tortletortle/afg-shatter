# AFG / 万物粉碎 — V0.14 凸体碰撞与接触岛版

V0.14 暂停扩充物件，重点升级刚体碰撞窄相与休眠管理。V0.12 的中空薄壁瓶、花盆、金属罐、材质、破坏工具、PBF 实验和解压模式均保留。

## 本版改动

### GJK / EPA 凸体窄相
- 每个 Voronoi / 薄壁分块提供凸多面体 support map。
- GJK 判断凸单元是否相交，EPA 计算穿透深度、法线与接触点。
- 复合刚体按 cell-pair 检测，先用单元包围球过滤。
- cell-pair 组合超过 1024 时使用保守包围球回退，并单独计数。
- 每个凸体使用 0.011 support contact skin（两侧总计 0.022），减少微小间隙造成的接触丢失。
- 低速接触使用零恢复系数，减少静止堆叠微弹跳；高速碰撞仍使用材质恢复系数。
- 角冲量使用球形近似转动惯量，不是完整惯性张量。

### 接触岛休眠 / 唤醒
- 当前接触对建立 union-find 接触岛。
- 接触岛动态刚体统一判断休眠。
- 休眠岛接触图跨帧保留，避免休眠对象跳过碰撞查询后丢失唤醒关系。
- 对岛中任一成员施加外部冲击时，唤醒同一岛的动态刚体。

### 遥测
新增 GJK 测试数、EPA 迭代数、EPA 退化回退、高复杂体回退、接触岛和休眠刚体计数。

## 运行
- `index.html`：优先尝试 WebGL2，初始化失败时回退 Canvas2D。
- `compat.html`：强制 Canvas2D，适合兼容性优先的设备。
- Windows 双击 `start.bat`，默认打开 `compat.html`。
- ChatGPT 内置预览可能禁用页面脚本，请解压后使用 Edge / Chrome 独立打开。

## 验证摘要
- 随机 OBB 对照 SAT：500 组，相交判定 0 错配，EPA 深度超阈值错配 0；平均绝对深度误差约 2.35e-16。
- 旧版 0.72 半径球形窄相在同一 500 组样本中出现 16 次漏检和 7 次误报。
- 两刚体 600 步仿真最终休眠；固定支撑堆叠验证接触岛保留与休眠。
- 中空玻璃瓶 84 cells / 156 bonds，体积误差约 2.22e-16，无非流形边与凸性错误。
- 桌面、手机、平板视口均加载成功，页面异常 0；破坏回归质量有限，地面最低点为 0（浮点容差内）；样本测试 EPA 与高复杂体回退均为 0。

## 未完成
- 不是 FEM，也不是完整材料断裂力学。
- 超过 1024 个 cell-pair 组合的复杂刚体对仍回退到包围球近似。
- 接触响应尚未使用多点 contact manifold 和完整惯性张量。
- PBF / CSF 真实流体精度仍未通过完整 Laplace / 动态基准。
- 真实 Windows、手机 GPU、WebGL2 路径尚未实机验收。
- OBB 基准是正确性测试，不是游戏帧率或整体性能提升证明。
