# AFG / 万物粉碎 — V0.15 多点接触与摩擦求解版

V0.15 暂停增加物件，集中升级碰撞响应质量。保留 V0.14 的 GJK/EPA 凸体窄相、接触岛休眠、中空薄壁容器、材质、破坏工具与 PBF 实验。

## 本版改动
- GJK/EPA 后提取参考面与入射面，执行 3D 多边形裁剪，建立多点接触流形。
- 每个法线簇最多 4 点、最多 2 个法线簇；无法可靠匹配时退回 EPA 单点。
- 6 轮 sequential impulse，累积法向冲量与库仑摩擦；加入滚动阻力。
- 地面碰撞改为多个底部顶点接触，复用同一摩擦求解器。
- 新增材料 toughness / friction / rolling 调校值，保留 cap 兼容别名。
- 按相对接近速度和重叠程度排序候选对；窄相耗时 EWMA 调整 GJK 预算（96–2400，目标约 2.2 ms）。
- 超预算或 cell-pair 超过 1024 时使用保守包围球回退，可能产生假阳性接触。

## 参数说明
材料参数是游戏调校值，不是实验测得的物理常数。完整参数与验证限制见 `VALIDATION.md`。

## 运行
- `index.html`：优先 WebGL2，失败时回退 Canvas2D。
- `compat.html`：强制 Canvas2D。
- Windows 双击 `start.bat`。
- ChatGPT 内置预览可能限制脚本执行，请用独立 Edge / Chrome 打开。

## 验证摘要
- GJK/EPA：9/9 回归；500 组 OBB vs SAT，相交错配 0、深度超阈值错配 0。
- 单凸体面接触生成 4 点；多 cell 合成场景 16 个原始点筛选为 4 点。
- 摩擦、滚动、地面多点接触与自适应预算单元测试通过。
- 600 步双刚体测试最终 2 个刚体休眠；720 步固定支撑堆叠测试接触岛保留。
- 内联 JS 语法检查通过。

## 限制
完整浏览器启动、真实 Windows、手机 GPU、WebGL2 和触摸交互尚未验收；测试使用抽取的物理函数与确定性 stub，不等同于实机测试。转动惯量仍是标量球形近似，PBF / CSF 精度仍未通过完整物理基准。
