# AFG / 万物粉碎 — V0.16 持久接触热启动版

V0.16 暂停扩充物件，集中降低重复接触求解成本。保留 V0.15 的多点接触流形、库仑摩擦、滚动阻力、材料调校、自适应窄相预算，以及此前的 GJK/EPA、接触岛、中空薄壁容器和 PBF 实验。

## 本版改动
- 新增跨帧接触缓存，以刚体 ID 对作为键。
- 将接触点两侧的局部锚点、法线和累计冲量保存在低 ID 刚体的局部坐标系中；匹配时同时检查锚点距离与法线方向。
- 下一帧先应用上一帧的法向冲量和切向冲量，再进行 sequential impulse 修正；切向冲量会重新投影到当前接触平面，并受库仑摩擦上限约束。
- 缓存最多保留 3 个未见模拟步，最多 4096 个刚体对；支持接触点一对一匹配、反向刚体顺序和过期清理。
- 自适应求解迭代：稳定且缓存命中的接触 2 轮，中等接触 4 轮，默认 6 轮，高速碰撞或深穿透 8 轮。
- 地面多点接触也使用同一套持久缓存和自适应迭代策略。
- 新增 Warm Start 命中数、缓存规模和平均求解迭代遥测。

## 运行
- `index.html`：优先 WebGL2，失败时回退 Canvas2D。
- `compat.html`：强制 Canvas2D。
- Windows 双击 `start.bat`。
- ChatGPT 内置预览可能限制页面脚本，请解压后使用独立 Edge / Chrome 打开。

## V0.16 验证摘要
- Warm Start 单元测试通过：包括刚体参数顺序反转、冲量复用、法向支撑消失时撤销旧摩擦冲量，以及缓存过期。
- 自适应迭代策略测试通过：覆盖 2 / 4 / 6 / 8 轮四种决策。
- 360 步四点地面接触基准：1440 个接触点中命中缓存 1436 个；平均迭代由冷启动 6.0 降至 2.011，迭代工作量减少约 66.5%。
- 同一基准中，热启动与冷启动均保持有限状态；最大穿透 0，接触后的最大速度约 0.000714。
- `index.html` 与 `compat.html` 两个构建各有 6 个内联 JavaScript 脚本块，均通过语法编译检查。

## 验证边界与限制
V0.16 的新基准使用从生产页面抽取的物理函数和确定性数学/材质 stub；迭代次数减少不等同于浏览器帧时间按同等比例下降。完整页面浏览器启动、真实 Windows、手机 GPU、WebGL2、触摸交互和真实场景性能尚未验收。转动惯量仍是标量球形近似，PBF / CSF 精度仍未通过完整物理基准。

可重复执行：`node tests/v16_warm_start_harness.js`（Node.js 22）。GitHub Actions 自动验收已通过。详细结果见 `VALIDATION.md` 与 `benchmark/v16_results.json`。
