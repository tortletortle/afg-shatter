# AFG 万物粉碎 V0.12 — 中空薄壁容器

## 运行
双击 index.html（普通版，先尝试 WebGL2，失败回退 Canvas2D），或 compat.html（强制 Canvas2D）。Windows 可运行 start.bat，默认打开兼容版。无需联网或安装库。HTML 预览容器可能禁用 JS；本版本不能保证 ChatGPT 内置预览正常显示。测试环境禁止 file:// 导航，测试通过 Playwright set_content 注入完整 HTML 进行，没有实际验证 Windows 启动脚本。

## 新增
- 三种开口容器：中空玻璃瓶（84 单元）、陶土花盆（96）、开口金属罐（96）。真实几何空腔、有限径向壁厚、实心底板。通过面顶点集合匹配连接，沿已有图连通性算法断裂。保持 V0.11 实心形状入口和原 PBF 代码。
- 容器碎片碰撞后的地面约束投影（只应用于中空容器）。
- 补全冰晶、铝合金、陶土的 WebGL 材质光学参数与渲染异常回退。启动失败诊断；默认中空花盆，避免启动加载复杂流体场景。

## 验收（本次实测）
运行 `python tests/test_v12.py`（测试环境依赖 playwright、Chromium）。`results/v12_results.json` 包含 3 种几何审计、9 组多种子冲击与 240 步后续模拟、14 个历史入口单次破坏回归、3 种视口 Canvas 布局与触摸/鼠标检查。几何体积与解析多边形棱台公式一致；所有采样点检查空腔、厚底及侧壁；边界边计数均为 2；本轮 9 组最终地面穿透为零。质量账面误差为零，能量账面误差不超过 1.43e-14（不是完整动力学能量守恒证明）。

## 限制
WebGL2 在运行环境不可用，未实际验证 GPU 路径；启动脚本未在 Windows 实测。预分块为规则环状凸体，未验证真实玻璃断裂力学，碎片间仍用近似球形碰撞，金属罐没有弹塑性形变，流体物理精度问题未解决。空腔壁厚是径向而非曲面法向恒定厚度；单位无物理标定。默认未放入液体或土壤。没有新增联网服务。
