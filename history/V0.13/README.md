# AFG / 万物粉碎 — V0.13 算法优化版

V0.13 暂停增加物件，优先优化刚体碰撞宽相、断裂图遍历、PBF 邻居搜索与流固碰撞筛选。保留 V0.12 的中空薄壁容器、材质、工具和交互。

## 算法改动
- **刚体宽相：** 将中心点单格哈希改为保守 AABB 多单元空间哈希。候选刚体写入其 AABB 覆盖的全部网格，查询后去重，再进入原有球形窄相。
- **断裂图：** 每个 cell 维护局部 bond links；断裂时复用局部边表与邻接图，连通分量遍历动态检查 bond 的 broken 状态。
- **PBF：** 使用 0.08 Verlet skin；邻居搜索半径为 h + skin，粒子最大位移超过 skin/2 时重建。物理核函数仍严格按 h 过滤。
- **流固耦合：** 增加独立的 fluidR，包住每个 cell 的流体接触球；不再错误地把几何顶点包围球直接用于放大接触球粗筛。
- **遥测：** 增加每步碰撞候选数、邻居重建次数、邻居候选数和流固宽相拒绝计数。

## 已验证结果
测试环境：系统 Chromium headless、Canvas2D、固定物理步长 1/120 s；不是手机或 GPU 实测。

- 85 刚体、96 cells 的花盆破坏场景：最后一步碰撞候选对 2497 → 569（减少 77.2%）。
- 刚体求解中位耗时：2.3ms → 2.1ms；P95 均为 4.9ms，整体帧耗时没有大幅下降。
- 断裂图微基准：activeEdges 中位耗时 12.1ms → 0.4ms；graphFor 4.9ms → 1.3ms；components 5.2ms → 3.6ms（85 bodies，100 次遍历，5 批中位数）。
- PBF 邻居覆盖：V0.12 在 240 次测量求解中发现 7,221 个流体邻居漏项和 3,372 个墙面邻居漏项；V0.13 对应测试为 0。PBF 平均耗时相近，主要收益是邻居覆盖正确性。
- 流固单次相同初始状态测试：cell 检测 1238 → 30（减少 97.6%），耦合耗时 22.9ms → 18.5ms，接触数两版均为 14。
- 回归：3 几何、9 破坏、17 旧入口、5 组随机 AABB、6 组 PBF 邻居覆盖、1 组流固耦合、3 种视口，全部通过。

## 运行
- `index.html`：优先尝试 WebGL2，失败时回退 Canvas2D。
- `compat.html`：强制 Canvas2D。
- Windows 可双击 `start.bat` 打开兼容模式。
- ChatGPT 内置 HTML 预览可能禁用 JavaScript，请使用独立 Edge / Chrome。

## 尚未完成
- WebGL2 和真实 GPU 性能未验收；Windows 启动脚本未在实体 Windows 设备上验收。
- PBF / CSF 物理精度与 Laplace 基准仍未通过完整物理验收。
- 刚体窄相仍为近似球形接触，不是凸体精确碰撞。
- 断裂模型仍是能量阈值 bond graph，不是 FEM 或真实材料断裂力学。
- 本版没有达成整体求解耗时降低 50% 的目标；不作此类宣称。
